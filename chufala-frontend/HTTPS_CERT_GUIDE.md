# HTTPS 证书配置与使用指南

本文档详细说明了项目中生成的四个证书文件的作用、关系以及正确的使用方法。

## 1. 文件清单与角色说明

这四个文件共同构成了一个完整的 HTTPS 信任链体系。

| 文件名 | 类型 | 角色 | 存放位置 | 作用 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`rootCA.key`** | 私钥 | **老总的私章** | **仅本地保存** | 用来签发证书。 | **绝对保密**，不可泄露，不可发送给他人。 |
| **`rootCA.pem`** | 公钥/证书 | **老总的公告** | **电脑/手机** | 安装在设备信任列表中。 | **核心文件**，所有设备必须安装它才能信任你的项目。 |
| **`key.pem`** | 私钥 | **员工的钥匙** | **项目根目录** | Vite 服务器用来解密数据。 | 配置在 `vite.config.ts` 中。 |
| **`cert.pem`** | 公钥/证书 | **员工的工牌** | **项目根目录** | Vite 服务器出示给浏览器看。 | 配置在 `vite.config.ts` 中。 |

---

## 2. 核心原理（通俗版）

1.  **生成阶段**：我们用 `rootCA.key`（私章）给 `cert.pem`（工牌）盖了个章。
2.  **信任阶段**：你在电脑/手机里安装了 `rootCA.pem`（公告），告诉设备“认准这个章”。
3.  **访问阶段**：
    *   浏览器访问项目。
    *   Vite 出示 `cert.pem`（工牌）。
    *   浏览器检查工牌上有 `rootCA` 的章，且设备里有 `rootCA` 的公告。
    *   **验证通过，显示绿锁（安全）。**

## 3. 正确使用步骤

### 场景一：本机开发（Windows 电脑）

1.  **安装根证书**：
    *   双击 `rootCA.pem`。
    *   点击 **“安装证书”**。
    *   存储位置选择：**“本地计算机”** (Local Machine) -> 下一步。
    *   选择 **“将所有的证书都放入下列存储”** -> 点击“浏览” -> 选择 **【受信任的根证书颁发机构】**。
    *   确定 -> 完成。
2.  **启动项目**：
    *   确保 `vite.config.ts` 中配置了 `key.pem` 和 `cert.pem`。
    *   运行 `npm run dev`。
3.  **访问**：
    *   浏览器访问 `https://192.168.1.103:8881`（必须与证书 IP 一致）。

### 场景二：手机局域网访问（iOS/Android）

1.  **发送文件**：将 `rootCA.pem` 发送到手机（通过 USB、蓝牙或 QQ/钉钉下载）。
2.  **安装根证书**：
    *   **Android**：进入 `设置` -> 搜索 `加密与凭据` -> `安装证书` -> 选择 **`CA 证书`** -> 选中 `rootCA.pem` 安装。
    *   **iOS**：
        1.  点击文件安装描述文件。
        2.  去 `设置` -> `已下载描述文件` -> 安装。
        3.  **关键一步**：去 `设置` -> `通用` -> `关于本机` -> `证书信任设置` -> 打开 `MyDevRootCA` 的开关。
3.  **访问**：
    *   手机浏览器访问 `https://192.168.1.103:8881`。

## 4. 常见问题排查

### Q1: 为什么安装了证书还是显示“不安全”？
*   **原因 1**：浏览器缓存。
    *   *解法*：使用**无痕模式**访问，或清除浏览器缓存。
*   **原因 2**：IP 变了。
    *   *解法*：检查电脑 IP 是否还是 `192.168.1.103`。如果变了，需要修改 `openssl.conf` 并重新生成 `cert.pem`（见下文）。
*   **原因 3**：安装位置不对。
    *   *解法*：确保 `rootCA.pem` 是安装在 **“受信任的根证书颁发机构”**，而不是“个人”或“中间证书颁发机构”。

### Q2: 电脑 IP 变了怎么办？（如变成了 192.168.1.200）
不需要重新安装手机/电脑的证书，只需要重新签发“工牌”：

1.  修改 `openssl.conf`：将里面的 `192.168.1.103` 全部改为 `192.168.1.200`。
2.  修改 `vite.config.ts`：将 `allowedHosts` 里的 IP 也改掉。
3.  运行以下命令重新生成 `cert.pem`：
    ```powershell
    # 生成新的私钥（可选，也可以沿用旧的）
    openssl genrsa -out key.pem 2048
    
    # 生成新的证书申请
    openssl req -new -key key.pem -out server.csr -config openssl.conf
    
    # 用之前的 rootCA 重新签名
    openssl x509 -req -in server.csr -CA rootCA.pem -CAkey rootCA.key -CAcreateserial -out cert.pem -days 365 -sha256 -extensions v3_req -extfile openssl.conf
    ```
4.  重启 Vite。

## 5. 备份建议
*   请妥善保管 **`rootCA.key`** 和 **`rootCA.pem`**。只要这两个在，你就可以随时为任何 IP 签发被信任的证书，而无需再次在手机上进行繁琐的安装步骤。
